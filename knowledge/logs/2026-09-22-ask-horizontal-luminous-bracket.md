# 2026-09-22 · Ask 对话收起态水平 { 状渐变流光拱落地

## 触发背景
在 Ask Asterism 升级为双侧气泡与右侧内容区居中后，针对展开收起机制，用户明确指出了真实视觉构想：不是一个小按钮小拉手，而是横跨输入框上方、形如水平躺倒大括号 `{` 的渐变流光光带效果。

## 变更内容

### 1. 水平 { 状渐变流光拱组件（AskLuminousBracket）
- **贝塞尔双曲几何**：
  - 路径：`M 0 22 C 60 22, 110 17, 150 10 C 175 5.5, 192 2, 200 2 C 208 2, 225 5.5, 250 10 C 290 17, 340 22, 400 22`；
  - 两翼贴合输入框上沿左右淡出，两腰双曲向上隆起，中央正上方汇聚为优雅的向上尖点，并在顶点放置微星聚光点；
  - 宽度达 `w-[88%] max-w-lg`，横跨输入框大部分宽度。
- **光学流光与渐变层级**：
  - 底层：粗线径带高斯模糊（`feGaussianBlur stdDeviation="3"`）的电光蓝冷光光晕（`#38bdf8` ~ `#818cf8` 线性渐变）；
  - 表层：晶莹纯白高光脊线（两端透明，中央 98% 白金锐利高光）；
- **微动效与交互**：
  - 悬停时：整条流光向上浮动 1.5px，光晕透明度由 75% 提至 100%，顶峰微星放大；
  - 点击：包裹全宽热区，点击流光任意区域即可丝滑向上展开对话气泡流。

### 2. 交互状态机保持完善
- 彻底废除右上角违和关闭按钮；
- 外部空白处点击（Click Outside）与按 Esc 触发可逆平滑折叠；
- 折叠状态下再次按 Esc 彻底清空；
- 输入框重新聚焦（Focus / Type）或提问自动恢复展开。
