# 2026-09-22 · 洞察页 UI/UX 深度重构与全页面浮层底部安全区

对「洞察（Insights/Dashboard）」页面的数据卡片、信息架构、图表体系以及全局 Ask Dock 浮层避让进行系统化深度优化：

1. **记忆唤醒（Resurface）去重与文案纠偏**：
   - 算法层（`packages/core/src/repos/resurface.ts`）：命中整年纪念日（`anniversary`）时自动抑制普通沉睡理由（`dormant`），彻底消除单张卡片内“5 年前今天收藏”与“1 年/5 年前收藏”自相矛盾与时间重复问题；
   - 文案层：修正 `zh-CN.json` / `en.json`，将 `dormant` 语义调整为“已沉睡 {{duration}} 未重温”；
   - UI 表现：原因理由重塑为微徽章（Chip）排布，层次更清晰；「待补全记忆」在保持上限 2 条以避免待办心理负担的同时，网格调整为 `md:grid-cols-2` 等宽并排，骨架屏同步镜像，彻底消除了宽屏 3 列下右侧缺失 1/3 的空缺感。
2. **大盘统计指标（StatCard）容器化与个人记忆维度**：
   - 使用 `@asterism/ui` 的 `Card` 容器包裹每个 KPI，增设微质感图标底框与悬停反馈，消除原先“裸奔悬空”的视觉断层；
   - 引入“个人记忆”指标（统计已有 whySaved / note 的 Star 数量及占比），直击 Asterism 作为“开源记忆库”的核心产品价值；
   - 动态避免双 0 占位：当尚无集合时，动态替换为“活跃状态占比（如 98% 活跃）”，杜绝空态下的尴尬与负向暗示。
3. **可视化图表体系全面重构（DashboardCharts）**：
   - 热门 Topic 柱状图由 -35° 倾斜文字彻底改造为**横向条形图**，长短 Topic 标签平展展示；
   - 语言分布与热门 Topic 均通过 `LabelList` 直出数量标签，无需 hover 即可快速扫读；
   - 收藏趋势面积图增加轴向内边距，解决年份首尾贴边裁切；
   - 右下角卡片解耦：顶部以现代化微型状态条呈现活跃与归档比例；有集合时展示横向进度排行榜，无集合时展示「集合整理正向引导卡片」，变被动空态为主动产品引导。
4. **全页面滚动容器底部安全边距（Safe Area Padding）**：
   - Ask Dock 保持纯粹的 fixed overlay 浮层（不占文档流，页面内容在滚动时背后自然穿透）；
   - 在所有具有可滚动主内容区的页面（`dashboard`、`browse`、`collections`、`collection-detail`、`settings`、`import-export`）内部滚动容器底部统一设置 `pb-24`（96px）；
   - 确保内容在滚动到底部时，最底部的最后一个元素刚好完整露在 Dock 上方，彻底杜绝触底时的视线遮挡与点击阻断。
