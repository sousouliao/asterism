# 2026-09-22 · 顶栏与浏览页工具栏极简化清理

针对用户反馈「上一个提交做定时同步是为了去掉重新连接 GitHub 按钮，结果顶栏没去掉反而浏览页多了两个按钮」的诉求，彻底收敛界面干扰：

1. **Browse 工具栏移除「当前 Star / 历史」切换**：
   - 移除 Browse 页面头部的 `[当前 Star]` 与 `[历史 (0)]` 切换控件；
   - 恢复使用 `useStarredRepos`，仅查询当前 Star 仓库，去除历史空状态等冗余分支，工具栏仅保留视图切换器（网格 / 列表）。
2. **Topbar 彻底移除常驻「重新连接 / 同步」按钮**：
   - 移除 Topbar 右侧常驻的 Tooltip 与 Button 节点，消灭突兀的黄色警告重连按钮；
   - 日常同步完全由开站静默同步和服务端后台定时任务静默接管，实现无感体验。
3. **收敛手动同步与重连入口至 UserMenu**：
   - 用户头像下拉菜单在正常连接时提供「同步」选项（支持手动触发并反馈 spin 动效）；
   - 凭据失效时在菜单内以轻量 warning 项提示「重新连接 GitHub」，不阻断且不污染全局 App Shell。

本地验证：
- `pnpm typecheck` 全部通过；
- `pnpm lint`（Biome）通过；
- `pnpm test` 全库 53 套件 282 项单测全绿；
- `pnpm build` 生产构建通过。
