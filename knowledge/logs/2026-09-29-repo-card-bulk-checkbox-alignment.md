# 2026-09-29 · 批量选择 Checkbox 移至卡片右上角消除布局重排

## 背景与问题

在浏览网格中进入批量选择模式（Bulk Selection）时，原实现采用 `pointer-events-none absolute top-4 left-4` 悬浮放置 Checkbox，并在卡片内容容器上强制叠加 `bulkSelection && 'pl-7'`（向右内边距偏移 28px）。
这导致：
1. **全局布局抖动（Layout Shift）**：用户进入选择状态时，网格内所有卡片的头像、标题、描述、话题标签及底部数据整体发生 28px 的水平右移与重新排版；
2. **截断加剧**：卡片内部有效宽度被压缩，原不换行的长标题和描述被强行截断。

## 解决与重构方案

1. **移除强制偏移**：彻底移除容器层上的 `bulkSelection && 'pl-7'`，保证卡片内部元素在普通模式与批量模式下基线完全一致，达到 **零偏移、零抖动、零布局重绘**；
2. **位置迁移至右上角**：
   - 将 Checkbox 移入第一行顶栏右侧的弹性盒（`flex shrink-0 items-center gap-1.5`）；
   - 在卡片内边距 `p-4` 下，该位置在视觉上精确贴合右上角（`top: 16px, right: 16px`）；
   - 与 `archived` / `unstarred` 徽章同级流式排布，避免绝对定位可能出现的遮挡冲突；
   - 左侧标题容器设置 `flex-1 min-w-0`，超长标题自然 `truncate` 并礼让右侧 Checkbox，两端分明。
3. **交互与测试保障**：
   - 保持整张卡片可点击选中的行为穿透；
   - 单元测试增加针对无 `pl-7` 偏移及 Checkbox 选中样式的断言。
