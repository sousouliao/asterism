# ADR 0049 · 退役重温收藏

- Status: Accepted
- Date: 2026-10-10
- Supersedes: ADR 0041

## Context

用户认为洞察页「重温收藏」实际用途有限，并明确要求移除且保持代码整洁。
收藏年限、纪念日、Star 数与最近 push 能解释候选来源，却不足以证明它与当前任务相关。
缺少个人记忆时卡片尤其缺乏上下文；补写旧收藏原因增加回忆成本。
Useful 与 Dismiss 都只隐藏候选 90 天，没有推荐学习回路。

## Trade-offs

保留或折叠该区块仍会留下无明确用途的算法、反馈与维护成本。
重新设计推荐或增加行为信号会扩大范围，目前没有已确认的新场景。
完整移除会失去纪念日式提醒，但现有搜索、Ask、Related Stars 已可服务按需检回。

## Decision

- 删除洞察页重温推荐区及专用加载 / 错误状态，页面直接呈现原有统计与图表。
- 删除专用卡片、理由展示、骨架、推荐算法与导出、本地反馈存储、开发预览路由、双语资源和对应测试。
- 保留个人记忆数量统计、Quick Look Memory 编辑、搜索、Ask、Related Stars、Collection 与同步能力。
- 不改数据库或历史 migration；旧本地反馈键停止读写，不增加一次性清理迁移。
- 历史日志与原始长期提案保留作背景，不作为恢复 Resurface 的授权。

## Consequences

洞察页聚焦统计，运行时不再维护重温推荐路径。
若未来提出主动推荐，须重新明确独立用户任务并新开决策，不直接复活本次退役代码。
